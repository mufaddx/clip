# Database Schema

## Purpose

Canonical table inventory for CLIP's PostgreSQL database, accessed exclusively through Prisma from `packages/db` (imported only by `apps/api` and background workers — see [`../architecture/SYSTEM_ARCHITECTURE.md`](../architecture/SYSTEM_ARCHITECTURE.md)). The actual Prisma schema lives at `packages/db/prisma/schema.prisma`; this document is the narrative reference kept in sync with it.

## Conventions

- Every table uses a UUID primary key (`id`), generated by the database (`gen_random_uuid()` via the `pgcrypto`/`uuid-ossp` extension, or Prisma's `@default(uuid())` at the application layer).
- Every table has `created_at` (default now) and `updated_at` (auto-updated on write).
- Soft delete (`deleted_at`, nullable) is used where historical/audit integrity matters more than hard removal — notably `users`, `campaigns`, `wallets`-adjacent rows are **never** hard-deleted; purely operational/ephemeral rows (e.g. expired sessions) may be hard-deleted per [`DATA_RETENTION.md`](DATA_RETENTION.md).
- Foreign keys are always indexed; status/enum columns used in list filters are indexed; `created_at` is indexed on any table paginated by recency.
- Money amounts are stored as integer minor units (e.g. cents) with a separate `currency` column, never as floating point.

## Table inventory

| Table | Purpose | Key relationships |
|---|---|---|
| `users` | Core identity: email, password hash, primary role, status | 1–1 with role-specific profile tables |
| `roles`, `permissions`, `user_roles` | RBAC — role definitions, permission definitions, user-to-role assignment | See [`../product/USER_ROLES.md`](../product/USER_ROLES.md) |
| `brand_profiles` | Brand org details (company name, website, industry) | belongs to a `users` row (owner) |
| `creator_profiles` | Clipper profile (bio, categories, trust score) | belongs to a `users` row |
| `admin_profiles` | Admin team metadata | belongs to a `users` row |
| `team_members` | Brand team membership + scoped permissions | links `users` ↔ `brand_profiles` |
| `categories` | Content/industry category taxonomy | referenced by campaigns, creator profiles |
| `instagram_accounts` | Connected IG account metadata | belongs to `creator_profiles` |
| `instagram_tokens` | Encrypted OAuth tokens | 1–1 with `instagram_accounts` |
| `campaigns` | The campaign entity + lifecycle status | belongs to `brand_profiles` |
| `campaign_assets` | Uploaded content/instructions | belongs to `campaigns` |
| `campaign_requirements` | Eligibility/targeting rules | belongs to `campaigns` |
| `campaign_creators` | Acceptance join table | links `campaigns` ↔ `creator_profiles` |
| `campaign_invitations` | Targeted invitations | links `campaigns` ↔ `creator_profiles` |
| `campaign_reels` | Submitted/detected reel | belongs to `campaign_creators` |
| `reel_verifications` | Verification outcome + reason | belongs to `campaign_reels` |
| `reel_metrics` | Latest known metrics (fast read) | belongs to `campaign_reels` |
| `metric_snapshots` | Immutable historical metrics | belongs to `campaign_reels` |
| `performance_rules` | Versioned scoring configuration | referenced by `performance_calculations` |
| `performance_calculations` | Qualified performance results | belongs to `campaign_reels`, references `performance_rules` |
| `wallets` | Cached balance buckets | belongs to `users` (brand or creator) |
| `wallet_ledger` | Append-only financial truth | belongs to `wallets` |
| `transactions` | User-facing grouping of ledger entries | groups `wallet_ledger` rows |
| `payments` | Provider deposit/payout attempts | referenced by `wallet_ledger` |
| `payouts` | Creator payout records | belongs to `withdrawals` |
| `withdrawals` | Withdrawal request state machine | belongs to `wallets` |
| `refunds` | Refund records | belongs to `wallets`, may reference `campaigns` |
| `referrals` | Referral attribution | links two `users` rows |
| `referral_rewards` | Issued/pending reward records | belongs to `referrals` |
| `notifications` | In-app notification instances | belongs to `users` |
| `notification_preferences` | Per-user channel preferences | belongs to `users` |
| `support_tickets` | Support ticket state | belongs to `users` |
| `ticket_messages` | Ticket thread messages | belongs to `support_tickets` |
| `disputes` | Dispute case state | may reference `campaigns`, `campaign_reels`, `payments` |
| `dispute_messages` | Dispute thread + evidence | belongs to `disputes` |
| `audit_logs` | Append-only admin action trail | references acting `users` (admin) |
| `system_settings` | Platform-wide configurable values | key/value + versioning where applicable |
